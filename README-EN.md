## 🧑🏻‍💻 Game Story Summary
The game’s overarching narrative depicts a hypothetical "Third Imposed War" between the **🇮🇷 IR IRAN ✊🏻** and the United States. The story unfolds from the perspective of a high-ranking political-military decision-maker; the choices this official makes alter the course of the conflict, though—mirroring the reality of the battlefield—Iran ultimately emerges victorious.

While the official is a fictional character—bearing a name chosen by the player—the war’s events are designed to be as realistic as possible, featuring actual figures and scenarios; only the protagonist himself is a fictional construct.

The game consists of short video sequences, a narrative storyline, player-driven decisions, and brief incidental events, all managed through a simple menu and settings interface.

### ▪︎ [**Danial Kamalipour**](https://GitHub.com/DanialKamalipour):
- Writing Story With This Way :
At First does Fork The Repasitory And Does Editing `Story.txt` Like This :
At the beginning of each new line (this does not apply to every single line, only new ones), one of the following symbols—along with its corresponding meaning—must be placed:

*   `*`: Use this if the story is to be narrated via the written text provided.

*   `**`: Use this if the story is to be narrated, but the text itself should not appear directly in the game; instead, this segment should be presented visually (via video) by the developers.

*   `1`: Use this to ask the player a question; Question 1 uses the number 1, Question 2 uses the number 2, and so on.

*   `1.1`: The first answer choice for Question 1; similarly, use 1.1, 1.2, 1.3, etc. (The user must select one of these options! | Questions must have a minimum of 2 and a maximum of 6 choices.)

So, the symbols are `*`, `**`, `1`, and `1.1` (note that the numbers are variable).
